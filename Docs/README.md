# Module documentation

This folder contains usage examples and API notes for each module in the package.

- [Totp.md](Totp.md) – time-based one-time password generation, validation, and provisioning URIs
- [QRCode.md](QRCode.md) – QR image generation from otpauth URIs
- [Passkey.md](Passkey.md) – challenge-based validation and WebAuthn-style registration/authentication helpers
- [Recovery.md](Recovery.md) – recovery-code batch generation and validation

For a complete package overview, see the root [README.md](../README.md).
